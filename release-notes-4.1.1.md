# Glide 4.1.1

Fixes a few bugs and refines the warm-launch experience.

## Highlights 🚀

- ⚡ **Launch Speed Boost** keeps Glide's window, decoder, and file-open broker warm for faster image opening.
- 🧠 **Tiny standby footprint** uses approximately 3–4 MB when the main window is closed.
- 🪟 **Windows Snap preservation** keeps edge snapping and Snap Layout behaviour on warm restores.
- 🛡️ **Privacy curtain** matches the active theme and prevents the previously opened image from being exposed during transitions.
- 🔗 **Single warm instance** prevents duplicate Glide processes and extra taskbar icons.
- 🖼️ **Same-image warm reopen** works correctly after closing and reopening the same picture.
- 🛠️ **Installer safety check** detects a running Glide instance and offers to close it before continuing.
