Fast, lightweight Windows image viewer: multi-tab/multi-window (each window its own taskbar button), overlay mode, native SVG/vector support, built-in decoders for TGA/PCX/PNM/QOI/HDR/WBMP/XBM/XPM/SGI, automatic Open With integration, Explorer thumbnails for all supported formats, ~16 MB installer, 196 routed extensions.
