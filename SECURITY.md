# Security

Glide is designed as a local image viewer.

- No account is required.
- No cloud service is required for normal viewing.
- The bundled codec build uses pinned source archives and SHA-256 verification.
- Runtime codec downloads are not required.
- File deletion uses Windows Recycle Bin semantics by default.

Image decoders process untrusted binary input. Please report crashes or malformed-file issues through GitHub Issues and avoid posting private images or sensitive diagnostic material publicly.
