# Documentation index

| Path | What it is |
|---|---|
| `ARCHITECTURE.md` | Subsystem map: where each feature lives, its tests and docs (start here before changing the app) |
| `ACTIONS-AND-HOTKEYS.md` | The master action registry: how hotkeys, gestures, menus, title-bar and status-bar buttons and Settings search come from one list; recipe for adding an action |
| `NAVIGATION-HISTORY.md` | Browser-style Back / Forward per tab: rules, keys, mouse side buttons, migration and tests |
| `NET10-MIGRATION-PLAN.md` | The .NET 8 to .NET 10 LTS migration (done in 5.0.1): findings, decisions (CET off), risks and the open follow-ups |
| `code-signing.md` | How release builds are signed (certificate via environment variables) |
| `explorer-thumbnails.md` | The native Windows Explorer thumbnail provider: design, quality presets, measurements |
| `format-coverage.md` | The route map for every recognised file extension and a comparison with IrfanView |
| `print-research.md` | Reference-behaviour study of other viewers' print dialogs and Glide's print window acceptance evidence |
| `GITHUB_ABOUT.txt` | The one-sentence GitHub About text and suggested topics |
| `GITHUB_DESCRIPTION.txt` | A longer product description for stores and listings |
| `audits/` | 2026-11 code hygiene, coupling and AI-maintainability audits, the combined staged plan, and stage notes |
| `history/` | Finished or point-in-time material: `GLIDE_MANIFESTO_AND_HANDOFF.md` (principles and the 5.0.x handoff; still the single handoff file the source ZIP carries), `CLEANUP-5.0.md`, the 5.0.0 / 5.0.1 publish checklists and ordered publish commands |
| `perf/` | Benchmark plans and results |
| `releases/` | Release notes per version (`release-notes-<version>.md`) and the 5.0.0 community feedback map |
| `screenshots/5.0/` | The 5.0.0 hero and Settings / Explorer captures used by the README and the release notes |
| `screenshots/print-research/` | Print window captures used by `print-research.md` and the README |

Other places: `../README.md` (front page), `../CHANGELOG.md` (every change; read only the top section), `../AGENTS.md` (rules for coding agents), `../tools/` (build, quick-check, benchmark and audit scripts; `tools/perf` is the benchmark harness), `../src/*/README.md` (one short page per project; `Glide.App` points back to `ARCHITECTURE.md`) and `../Archive/` (git-ignored backups and legacy material, not part of the repository).
