# Glide 4.1.7

- 🎞️ Animate individual Window-in-Window overlays with refresh-synchronised smooth movement.
- 🧭 Configure each overlay independently by region, speed, turn behavior, and interaction pausing.

- ✨ Animate or stop all overlays directly from an overlay context menu.
- 🧹 Close all open overlays directly from the context menu.
