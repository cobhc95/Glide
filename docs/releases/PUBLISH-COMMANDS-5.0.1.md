# Publish commands for Glide 5.0.1 (ordered)

For the lead, to run after the owner has reviewed the release material. **Nothing here has been run.** Commands are PowerShell. Adjust the two paths in step 0. Read `RELEASE-5.0.1-CHECKLIST.md` first (sections 1 and 2).

The release notes show their pictures from `https://raw.githubusercontent.com/cobhc95/Glide/main/docs/screenshots/5.0/...`. Those images were published with 5.0.0 and are already on `main`; step 5 still checks that they are reachable before the release is created.

## 0. Variables

```powershell
$src   = "<path to the project folder>"                  # the project folder
$clone = "C:\Temp\glide-repo"                           # a CLEAN clone of cobhc95/Glide (created in step 1)
$rel   = "$src\dist-installer\release-5.0.1"            # Glide.Setup.exe, Glide-5.0.1-Portable.zip, Glide.Setup.sha256
```

```powershell
Get-Content "$rel\Glide.Setup.sha256"                        # <hash>  Glide.Setup.exe
```

If the installer was rebuilt since the notes were written, update the SHA256 line in `docs/releases/release-notes-5.0.1.md` first.

## 3. Sync the source tree into the clone (mirror, with exclusions)

`/MIR` also deletes files in the clone that no longer exist in the project. `.git` is excluded so history is untouched.

Excluded on purpose (mirrors `.gitignore` plus the loose folders it does not cover):

| Excluded | Why |
|---|---|
| `Archive\` | backups and legacy files; `.gitignore` only covers a few patterns inside it |
| `.artifacts\`, `artifacts\` | generated build and packaging output |
| `dist\`, `dist-installer\`, `dist-portable\` | build output and release files |
| `build-output.txt`, `installer-output.txt`, `*.log` | build logs (`*-output.txt`, `*.log` are in `.gitignore`) |
| `Glide-*.exe`, `*.zip` (including `Glide-5.0.0-Portable.zip`, `Glide-5.0.1-Portable.zip`, `Glide-Zero-Context-Handover.zip`) | release artifacts (`/Glide-*.exe` and `*.zip` are in `.gitignore`) |
| `Glide Setup.exe` | build output name (in `.gitignore`) |
| `.vs`, `.idea`, `.vscode`, `*.user`, `bin`, `obj`, every `build` folder (including `native\*\build`) | local and generated |
| `TestResults`, `coverage`, `diagnostics-out`, `*.pdb` | test and symbol output |
| `AvaloniaUI` (generated XAML compiler caches under `src\*` and `tests\*`) | `.gitignore`: `**/AvaloniaUI/BuildServices/` |
| `native\third_party\ffmpeg` | fetched by `tools\fetch-ffmpeg.ps1`, never committed |
| `codecs\codecs.index.json` | generated by the build |

```powershell
robocopy $src $clone /MIR /XD .git Archive .artifacts artifacts dist dist-installer dist-portable .vs .idea .vscode bin obj build TestResults coverage diagnostics-out AvaloniaUI "$src\native\third_party\ffmpeg" `
  /XF build-output.txt installer-output.txt *.log *.zip Glide-*.exe "Glide Setup.exe" "Glide Setup.sha256" *.user *.pdb codecs.index.json /NFL /NDL /NP
# robocopy exit codes 0-7 are success; 8 and above are errors.
if ($LASTEXITCODE -ge 8) { throw "robocopy failed ($LASTEXITCODE)" }

# a stray 0-byte file in the project root (the real one is src\Glide.App\MainWindow.TitleSettings.cs)
if (Test-Path "$clone\MainWindow.TitleSettings.cs") { Remove-Item "$clone\MainWindow.TitleSettings.cs" }
```

Note: `/XF Glide-*.exe` and `*.zip` apply at every depth; the repository contains no tracked files that match them (the `.gitignore` already excludes both).

## 7. Create the release (title has no version number)

Assets: `Glide.Setup.exe`, `Glide-5.0.1-Portable.zip`, `Glide.Setup.sha256`, all from `dist-installer\release-5.0.1`. Do not upload `Glide-5.0.1.exe` or `Glide-Zero-Context-Handover.zip`.

```powershell
Set-Location $clone
gh release create v5.0.1 `
  --repo cobhc95/Glide `
  --title "Glide Image Viewer: .NET 10, safer file operations and update alerts" `
  --notes-file docs/releases/release-notes-5.0.1.md `
  --latest `
  "$rel\Glide.Setup.exe" `
  "$rel\Glide-5.0.1-Portable.zip" `
  "$rel\Glide.Setup.sha256"
```

To review on GitHub first, add `--draft` and publish the draft from the web page. The notes file must stay under GitHub's 125,000 character limit (it is about 22,000).

## 8. Verify

```powershell
gh release view v5.0.1 --repo cobhc95/Glide --json tagName,name,isDraft,assets --jq '{tagName,name,isDraft,assets:[.assets[].name]}'
$t = Join-Path $env:TEMP "glide-5.0.1-verify"; New-Item -ItemType Directory -Force $t | Out-Null
gh release download v5.0.1 --repo cobhc95/Glide --dir $t --clobber
certutil -hashfile "$t\Glide.Setup.exe" SHA256
Get-Content "$t\Glide.Setup.sha256"
```

Then open the release page and the repository front page and check that tables, the bar column, links and every image render. Run hand check 11 of the checklist (update check, up to date) with the downloaded portable build: it must report *You're up to date (5.0.1)*.
