# Glide 4.1.6 — overlay stability release

- 🖼️ Fixes an instant crash when opening multiple instances of the same overlay image.
- 🔒 Prevents overlay bitmap lifecycle from interfering with or disposing shared cache entries in the primary viewport.
- 🛡️ Adds defensive rendering error boundaries for Window-in-Window overlays.
- 📦 Includes the installer (`Glide Setup.exe`) and portable package (`Glide-4.1.6-Portable.zip`) for Windows x64.
