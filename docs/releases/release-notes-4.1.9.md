# Glide 4.1.9

## Highlights

- 📁 Audited folder-boundary traversal so nested picture branches are not skipped.
- 🔤 Kept alphabetical folder order as the default, with optional oldest-first modification-date and creation-date ordering.
- 🧭 Added deterministic tie-breaking and stale-navigation protection for safer folder transitions.
- 🖼️ Restored native overlay zoom/enlarge interaction and the on-overlay transparency slider.
- ↔️ Added independent width-only and height-only overlay resizing; the bottom-right handle still resizes proportionally.
- ✨ Improved high-refresh overlay motion timing and reduced zig-zag after manual repositioning or resizing.
