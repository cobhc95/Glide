# Community feedback that shaped 4.7 and 5.0.0

Thank you to [vertigo220](https://github.com/vertigo220), who filed all three public issues so far
([#1 UI improvements/issues](https://github.com/cobhc95/Glide/issues/1),
[#2 Explorer tab](https://github.com/cobhc95/Glide/issues/2),
[#3 GIF controls](https://github.com/cobhc95/Glide/issues/3)) and kept testing each build with numbered, reproducible reports.

This page maps every concrete item from those issues (read from the issue bodies and comments) to what shipped. "Shipped in 4.7.0"
items were already released; "Shipped in 5.0.0" items are new in this release. Where an item is checked against the source, the
setting or action id is named. The three issues were still open on GitHub when this page was written; they can be closed
(or answered) after 5.0.0 is published.
