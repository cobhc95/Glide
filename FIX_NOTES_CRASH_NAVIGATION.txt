Glide crash/navigation fix package

Changes in this package:
1. Slideshow async-void timer hardened:
   - no overlapping slideshow ticks
   - session-generation invalidation on pause/resume/stop/dispose
   - checks session validity after awaited navigation steps
   - catches/logs unexpected timer exceptions instead of allowing UI-thread process termination
2. Home now owns the same navigation serialization gate for the entire workspace transition.
   - stops slideshow/held navigation under the gate
   - invalidates pending image/decode requests before changing workspace
3. Slideshow presentation re-checks IsRunning and image visibility after obtaining the navigation gate.
4. Refinement presets retuned:
   - Maximum speed: 60 ms
   - Balanced: 20 ms
   - Maximum quality: 5 ms
   - schema migration updates untouched legacy preset values
5. Window restore behavior:
   - existing normal/maximized restore semantics retained
   - minimized continues to restore the pre-minimize state
   - ForceExit/tray Exit now persists placement/state before explicit shutdown
6. Previous preview recovery and slideshow prepared-frame/prefetch changes retained.

Runtime compile/test was not performed in this environment because the .NET SDK is unavailable.
