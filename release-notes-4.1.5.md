# Glide 4.1.5 — window placement stability release

- 🪟 Restores the saved non-maximised window position after the native Windows frame is shown.
- 🖼️ Opens an image launched from Explorer directly without leaving an unrelated Home tab behind.
- 🚀 Keeps Speed Boost warm external opens focused on the requested image instead of creating a standalone Home tab first.
- 🧭 Prevents warm standby reopen races from leaving hidden Alt-Tab windows or duplicate Glide taskbar icons.
- 🖱️ Makes fullscreen left-click move backward through images, matching the requested slideshow/navigation flow.
- 🎞️ Adds slideshow-only right-click stop, Enter-to-start in the slideshow prompt, and a configurable HQ playback indicator.
- ⚙️ Adds settings for slideshow right-click stopping and the playing-quality indicator, enabled by default.
- ✅ Preserves the existing maximised-state, resizing, Explorer opening, Speed Boost, and tab behavior fixes.
- 📦 Includes the installer and portable package for Windows x64.
