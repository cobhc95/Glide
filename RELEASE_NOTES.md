# Glide Alpha 0.12107

Initial public alpha release of Glide, a lightweight and deeply configurable Windows image viewer.

Highlights:

- very fast image opening and rapid folder navigation;
- persistent select-to-zoom rectangle;
- drag-friendly native window movement;
- configurable windowed/fullscreen mouse gestures;
- extensively remappable hotkeys;
- Home, image and folder/browser tabs;
- tab duplication, restoration and tear-off;
- sibling-folder navigation;
- slideshow and fullscreen;
- Window-in-Window reference-image overlays;
- customizable picture-index text overlay;
- searchable Settings;
- configurable status bar;
- 196 registered image-related suffixes;
- bundled WebP, HEIF/HEIC, AVIF, JPEG XL, JPEG 2000 and OpenEXR codec paths;
- offline, checksummed codec source bundle;
- built-in automated diagnostics;
- portable and installer workflows.

This is an alpha build. Some specialist formats require Windows/application-provided preview handlers, full animated WebP playback is not yet claimed, and tab tear-off/native Snap behaviour remains an area of refinement.

**Download:** `Glide_Setup_Alpha_0.12107_x64.exe`
