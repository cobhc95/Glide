# Glide 4.7.1

A polish release following 4.7.0, based on more community testing.

## Changes

- **Collapsed status bar is now just the expand button**, with no shaded panel around it.
- **Title-bar buttons nearest the window controls stay.** When the window is too narrow, the leftmost buttons hide first, so Settings stays visible the longest.
- **Right-click the Always on top button** to turn it on or off and pick Hard or Soft mode right there.

Everything from [4.7.0](https://github.com/cobhc95/Glide/releases/tag/v4.7.0) (animated GIFs, Fit to window, tab and status-bar improvements) is included.
