# Glide 4.6.1

## Folder position counter

See where the current folder sits among its siblings, beneath the image counter. Turn on **Show folder position under image counter** in Settings; it is off by default. To include the parent folder's position within the grandparent, also enable **Include parent folder position in folder counter**. For example, `5/50/4` means folder 5 of 50, with its parent in position 4. The counter follows the sibling-folder order and hidden-folder setting.

Both options are searchable in Settings using terms such as “folder counter” or “grandparent”.
